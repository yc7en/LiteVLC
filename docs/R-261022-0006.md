# R-261022-0006：README 补软件截图

## 变更背景与原因

1. GitHub 首页只有文字，用户无法直观看到播放器的界面风格与在线搜索的形态。
2. 用户提供两张实际运行截图：主窗口（播放控制栏 / 菜单）与「在线片源」搜索窗
   （多源并发搜索 + 选集 + 加入播放列表）。
3. 两份 README（英文 / 中文）必须同时加，避免中英分叉（见 R-261022-0004 的约定）。

## 变更具体内容

1. 截图入库（PNG，共约 70 KB，不影响克隆体积）：
   - `docs/images/screenshot-main.png` —— 主窗口；
   - `docs/images/screenshot-online-search.png` —— 在线片源搜索窗。
2. 两份 README 的首段介绍之后、第一个分隔线之前插入图片块：
   - 用 `<p align="center">` 居中，`width="640"` 控制展示宽度（原图 1030px 偏大）；
   - `alt` 文案各用对应语言；两图纵向排列，第一张是主窗口、第二张是在线搜索。
3. 路径用相对路径 `docs/images/...`，GitHub 网页与本地 Markdown 预览都能显示；
   不用外链图床，避免图床失效后首页开天窗。
