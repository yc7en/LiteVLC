# R-261021-0004：应用图标 / 手动更新预留 / Windows 11 安装包

## 一、变更背景与原因

1. 播放器没有专属图标（exe、任务栏、快捷方式都是默认图标），不像一个正式软件。
2. 需要预留「手动检查更新」能力：更新服务器地址按约定**混淆存放**（XOR+Base64 三段乱序，见 `src/core/UpdateService.cpp`），要求**不自动更新、只留手动入口，且该地址不能明文暴露**在源码/文档/界面中。
3. 需要能打出 Windows 11 使用的安装版（开始菜单、桌面快捷方式、可卸载）。
4. 现有配置写入策略是「永远写在 exe 旁边」，装进 `Program Files` 后普通用户无写权限，设置/进度/片源会**静默保存失败**，必须一并修掉。

## 二、变更具体内容

### 1. 应用图标
- 新增 `resources/icons/app.svg`（深色圆角方块 + 蓝白播放三角 + 渐变描边），与现有暗色主题同风格。
- 图标生成器（临时工具，不在仓库内，位于 `E:/tmp/icongen`）：QSvgRenderer 渲染 16/24/32/48/64/128/256 七档 PNG，按 ICO 格式（Vista+ PNG 压缩条目）手工拼出 `resources/app.ico`，另存 16/32/64/256 四档 PNG 进 qrc。
- `resources/app.rc`：windres 资源脚本，内嵌 exe 图标 + VERSIONINFO（1.1.0，纯 ASCII 避免 windres 编码问题）。
- `main.cpp`：`QApplication::setWindowIcon` 从 qrc 多尺寸 PNG 组装，标题栏/任务栏/Alt+Tab 全覆盖。

### 2. 手动更新（预留，不联网）
- 新增 `src/core/UpdateService.h/.cpp`：
  - `kUpdateEnabled = false`（总开关，预留）；
  - 更新地址混淆存放：明文 → 逐字节 XOR 0x5A → Base64 → 切三段**乱序**放在 `kChunks`，`kOrder` 记录还原顺序，运行时在内存拼回；源码、日志、界面、配置、文档均无明文；
  - `manifestUrl()` 预留清单地址拼装（`http://<host>/update/<platform>/manifest.json`，接入时可调）。
- `MainWindow` 新增「帮助(&H)」菜单：「检查更新」当前只回显版本号与预留说明，**不发起任何网络请求**；另有「关于」对话框。
- 后续接入步骤：`kUpdateEnabled` 置 true，在 `onCheckUpdate()` 里用 `QNetworkAccessManager` 请求 `UpdateService::manifestUrl()`，比对版本后提示下载即可。

### 3. Windows 11 安装包
- 新增 `package.bat`（CRLF，UTF-8 + chcp 65001）：编译 → 重建 `dist\LiteVlcPlayer` → `windeployqt`（含 compiler-runtime、tls/qnetworklistmanager 插件）→ 复制 `libvlc.dll`/`libvlccore.dll`/`plugins` → 调 Inno Setup 编译。ISCC 查找顺序：`%INNO_SETUP%` → `E:\tools\innosetup\ISCC.exe`（本机便携版，Inno Setup 6.0.5 解包部署，免安装）→ 默认安装目录。
- `installer.iss` 重写：相对路径（跟随脚本目录）、`SetupIconFile` 图标、安装程序自身版本信息、简体中文优先、卸载时清理 `%APPDATA%\LiteVlcPlayer` 用户数据、产物 `dist\installer\LiteVlcPlayer-<版本>-Setup.exe`（lzma2/ultra64，实测 33.8MB / 331 个文件）。
- 版本统一从 1.0.0 升到 **1.1.0**：CMake `project(VERSION)` → `APP_VERSION` 宏 → `installer.iss /DMyAppVersion` → `app.rc`。

### 4. 配置目录回退（BugFix 性质，随本需求一并修）
- 新增 `src/core/AppPaths.h/.cpp`：`dataDir()` 优先程序目录（绿色版就地存），exe 位于 `Program Files*` 下或目录不可写时回退 `%APPDATA%\LiteVlcPlayer`；`ConfigManager`（player_config.json）与 `SourceManager`（sources.json）统一改走它。

## 四、验证

- 混淆还原单测（Qt 小工具）：`kChunks`+`kOrder` 拼回后与预期地址逐字符一致（曾发现段序 bug：数组顺序即还原顺序，乱序必须放在存储侧，已修）。
- AppPaths 单测：把 `ProgramFiles` 环境变量指向 exe 所在目录模拟安装版，`dataDir()` 正确回退 `C:/Users/<user>/AppData/Roaming/LiteVlcPlayer`。
- exe 属性面板：FileVersion/ProductVersion 1.1.0，描述「LiteVLC Player」，任务栏/资源管理器显示新图标。
- `package.bat` 全流程跑通，产物 33.8MB；`innoextract -l` 确认包含全部 331 个文件（Qt 运行库、tls 插件、VLC 插件）。
- 已知 cosmetic：Inno 6.0.5 写入的版本字符串尾部有填充空格（Raw 值 1.1.0.0 正确，Explorer 显示正常）；`PrivilegesRequired=admin` + 卸载清 `{userappdata}` 有告警，属预期（同用户提权安装/卸载时行为正确）。
