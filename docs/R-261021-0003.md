# R-261021-0003 在线剧集加入播放列表 + 搜索窗改为非模态

## 一、变更背景与原因

两个用户诉求，本质是同一个断点：**在线播放和本地播放是两套互不相通的队列。**

### 1. 剧集进不了播放列表

改造前，`SourceDialog` 通过 `OnlinePlayRequest` 把「整条线路」塞给 `MainWindow::playOnlineEpisode`，
`MainWindow` 内部维护一份 `m_onlineRequest` 临时队列：

```
SourceDialog → OnlinePlayRequest → m_onlineRequest（临时队列） → playOnlineEpisode → StreamResolver → VLC
本地文件    → PlaylistManager（持久列表）                       → loadAndPlayFile  → VLC
```

后果：

- 右侧「播放列表」面板永远只有本地文件，在线剧集播完（或点「下一集」）就再也回不去；
- 播到最后一集直接 `stop`，`m_onlineRequest` 被清空，用户想重看某集只能重新搜一遍；
- 「顺序 / 列表循环 / 单曲循环」三种播放模式对在线内容完全失效；
- 上一集 / 下一集 / PgUp / PgDn 在两条路径下各写一套分支，行为不一致。

### 2. 搜索窗锁住主窗口

`MainWindow::onOpenOnlineSearch()` 用的是 `m_sourceDialog->exec()`。`QDialog::exec()` 会临时把窗口
提升为 **ApplicationModal**，在它关闭前主窗口收不到任何输入：

- 想暂停、拖进度、切集，必须先关搜索窗；
- 想连着挑两三部剧，每挑一部都要重开一次，关键词还得重打（`done()` 里清空了状态）。

## 二、目标与非目标

**目标**

1. 搜索到的剧集可以「加入播放列表」，与本地文件混排在同一张队列里；
2. 播放、上一集/下一集、播完续播、播放模式全部由 `PlaylistManager` 单一索引驱动；
3. 搜索窗改为非模态，开着它也能操作主窗口；点「播放」不关窗，方便连续挑选。

**非目标**

- 不做播放列表持久化（重启后在线条目失效，因为地址带时效签名）；
- 不做在线资源的「收藏 / 追剧」；
- 不改 `StreamResolver` 的解析逻辑（复用现有链）。

## 三、变更具体内容（设计）

### 3.1 抽象出 `PlaylistEntry`

`PlaylistManager` 原来存的是 `QStringList m_files`，只表达「本地路径」。新增
`src/core/PlaylistEntry.h`：

```cpp
struct PlaylistEntry {
    enum Kind { Local, Online };
    Kind   kind      = Local;
    QString location;   // 本地绝对路径 或 在线播放地址
    QString title;      // 列表显示名
    QString subtitle;   // 在线为来源站名
    QString userAgent;  // 仅 Online
    QString referer;    // 仅 Online
};
```

关键点：**UA / Referer 跟着条目走**。不同源需要不同请求头，同一张列表里混排多个源的剧集时不会串味。

### 3.2 队列改造

| 旧接口 | 新接口 |
|---|---|
| `files()` → `QStringList` | `entries()` → `QList<PlaylistEntry>`；`files()` 保留为兼容视图 |
| `currentFile()` | `currentEntry()` / `currentLocation()` |
| `addFiles(QStringList)` | `addEntries(QList<PlaylistEntry>)`；`addFiles` 内部转 Local |
| — | `entryAt(i)` / `indexOf(location)` |
| `nextFileManual()` / `previousFileManual()` | `nextEntryManual()` / `previousEntryManual()` |
| `nextFileOnEnd(mode)` | `nextEntryOnEnd(mode)` |

去重键统一用 `location`：本地是绝对路径，在线是播放地址。重复加入时不新增条目，只刷新标题/来源
（接口数据可能变过）。

顺带修了一个老问题：`removeAt()` 删掉当前项之前的条目时，`m_currentIndex` 没有前移，导致高亮错位。

### 3.3 统一播放入口

`MainWindow::playPlaylistIndex(int index)` 成为唯一入口：

```
playPlaylistIndex
    ├─ Local  → loadAndPlayFile(location)
    └─ Online → playOnlineEntry(index) → StreamResolver → VlcPlayer::openUrl
```

删掉 `m_onlineRequest` / `hasOnlineQueue()` / `playOnlineEpisode` / `playNextOnlineEpisode` /
`playPrevOnlineEpisode` / `clearOnlineQueue` 六个符号，用 `m_resolvingIndex` 记录「当前在播第几项」，
`StreamResolver` 的回调改为按该下标回查条目取 UA/Referer/标题。

上一集 / 下一集 / PgUp / PgDn / 播完续播 / 双击列表项全部走它，不再有本地与在线的分支。

### 3.4 搜索窗：双按钮 + 非模态

右侧剧集面板底部：

| 按钮 | 行为 |
|---|---|
| ▶ 播放选中剧集 | 整条线路加入列表，定位到选中集并播放 |
| ＋ 加入播放列表 | 只加入，不打断当前播放 |

两者都**不关闭窗口**，底部提示行（`m_actionHint`）反馈结果，例如
`✓ 已加入播放列表：《凡人修仙传》共 24 集（已存在的不重复添加）`。

非模态相关：

- `onOpenOnlineSearch()` 从 `exec()` 改为 `show() + raise() + activateWindow()`；
- `SourceDialog` 显式 `setWindowModality(Qt::NonModal)`；
- 新增 `showEvent` 覆盖：重新打开时复位 `m_ignoreResults`（该标志在 `done()` 里置位，用于丢弃关窗后的迟到回调；
  若非模态下反复开关，不复位会导致第二次搜索收不到任何结果）；
- 首次打开时 `placeBesideParent()`：屏幕右侧或左侧能腾出 ≥760px 就贴过去并排显示，否则保持居中
  （窗口只自动摆一次，之后用户拖到哪就留在哪）。

### 3.5 连播保护（本次顺带修复）

统一队列后，`onMediaEndReached` 由「线路播完就停」变成「按播放模式取下一条」。这带来一个新风险：
**坏流会「秒结束」**，于是自动连播会把整季瞬间跳完（实测 mock 环境下 5 秒跳完 3 集并循环）。

加两道闸：

1. `isStreaming() && durationMs() <= 0` → 这一集根本没拿到有效媒体，停止连播并提示；
2. 10 秒窗口内自动连播超过 3 次 → 判定为坏流连环跳，停止并提示换线路。

用户任意一次主动播放（双击列表、上一集/下一集、搜索窗点播放）都会重置计数器。

## 五、验收标准

1. 搜索窗打开后，主窗口可正常接收操作（非模态）；
2. 「＋ 加入播放列表」后右侧列表出现该线路全部剧集，标题为「剧名 · 第 N 集」；
3. 「▶ 播放选中剧集」后列表高亮定位到选中集，并真正起播；
4. 播完一集自动续下一集，顺序/循环/单曲三种模式生效；
5. 上一集 / 下一集 / PgUp / PgDn 在在线条目上行为正确；
6. 重复加入同一线路不产生重复条目；
7. 坏流不会把整季瞬间跳完。

## 七、已知限制

1. 在线条目不进配置文件，重启后清空（地址有时效签名，存了也播不了）；
2. 加入的是「整条线路」，暂不支持只勾选某几集（后续可按多选实现）；
3. 若源里同一部剧有多条线路，切换线路需要重新在搜索窗选一次，目前不会自动换线；
4. `playNextPlaylistEntry` 在只有一个条目时会回到自身并重播，这是既有的手感，未改动。
